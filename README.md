# Arnav Yadav — Portfolio

A custom-coded, high-performance portfolio featuring scroll-driven choreography, procedural visual elements, and dedicated system case studies.

## Tech Stack

| Layer | Choice | Details |
|---|---|---|
| Framework | React 19 | Client-rendered SPA |
| Language | TypeScript | Strict configuration |
| Build Tool | Vite | Fast HMR & production bundling |
| Styling | Tailwind CSS v4 | Token-driven design system |
| Scroll Animation | GSAP + ScrollTrigger | Iris reveal, pinned timelines, parallax |
| Smooth Scrolling | Lenis | GSAP ticker-synchronized momentum scroll |
| 3D & Procedural | Three.js & HTML5 Canvas | GPU-accelerated motion without heavy video |

## Key Features

- **Scene 1 — Hero Iris Reveal:** Pinned circular clip-path reveal expanding from center with staggered character typography.
- **Scene 2 — About & Academics:** Profile breakdown featuring 9.33 CGPA, semester highlights, and core engineering pillars.
- **Scene 2.5 — Technical Arsenal:** Bento grid showcasing backend systems, languages, relational database modeling, and CS theory.
- **Scene 2.8 — Sideways Journey:** Pinned horizontal scrolling track displaying academic, AI, and campus leadership milestones.
- **Scene 3 — Featured Projects:** Selected system highlights including Sugar Guard, Inventory Management System, and GrocAI Data Platform.
- **Scene 3.5 — Story:** Pinned scroll narrative on software engineering from first principles.
- **Scene 4 — Contact:** Direct communication channels, LinkedIn, GitHub, and downloadable resume.
- **Dedicated Case Studies Page (`/projects`):** Multi-page client-side router with category filtering across AI/ML, Backend, and Distributed Monorepos.

## Local Development

